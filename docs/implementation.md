# Approved implementation contract

Visual approval: v001 approved in chat, with the requested addition of species selection and spawning. Preserve approved layout; do not generate another mockup for this bounded control addition.

Core acceptance:
- A real 3D Earth with recognizable land, grid, poles, atmosphere and a date/time-driven day/night terminator. Rotate by dragging, zoom by wheel/pinch/buttons, reset view; keyboard equivalents.
- Multiple distinct flocks, each with individual birds and independent species/color identity. Tangential 3D velocities, separation/alignment/cohesion, normalization back onto a spherical flight shell, no longitude wrapping or pole singularity failures. Bounded flock/total size, predictable error feedback.
- Species choices: Arctic tern, Canada goose, Barn swallow and Common starling, with visibly different illustrative speed/cohesion/seasonal target tendencies. Do not promise field-calibrated biology or real migration corridors. Original default legend groups may be renamed to actual species. Arbitrary spawn coordinates remain a sandbox, not verified habitat suitability.
- Spawn panel: labelled species selector, bird count, latitude/longitude inputs (keyboard alternative to picking). A click on the globe selects coordinates only when pointer movement is below drag threshold; dragging must not relocate selection. Spawn button adds an independent flock at that location, with success/error status and updated counts. Repeated spawning is possible up to a visible cap. Spawn while paused remains paused and still renders. Reset simulation restores original flocks, settings and time consistently.
- Date/day-of-year or date input, UTC hour, playback pause/resume and speed selector, clickable month timeline. Time controls affect actual sun direction, opposite hemisphere seasons, polar day/night and seasonal migration targets; changing daylight affects model bird activity/speed. Species differences are genuine per-flock parameters, not only display labels.
- Maintain UTC rollover across midnight/year boundaries; distinguish illustrative visual flight speed from wall-clock time. Limit frame delta and avoid hidden-tab time explosions. Pause freezes both birds and simulation clock while preserving orbit/zoom and manual date changes. Reduced-motion starts paused, with user opt-in Play.
- Sidebar with global separation/alignment/cohesion sliders whose actual coefficients affect simulation; flock/species legend; truthful live bird/flock totals. Phone layout stacks without horizontal overflow, usable controls and no canvas covering controls.
- No backend, accounts, remote telemetry, data persistence or live observations. Bundle needed earth data; app should make no third-party runtime requests once served. No unnecessary dependencies; prefer Three.js + Vite + native DOM and node:test. Checkpoint small model tests, then app.

Tests: finite unit sphere positions and tangential velocities through poles/antimeridian, flock membership/isolation, distinct profiles, spawning validation/caps, date rollover, north/south solstice and polar daylight, equator/equinox, stable pause and changing slider effects where practical. npm run check = tests plus build. Parent must freshly exercise browser interactions, desktop and 390px layout, rendering and console/errors after builder finishes.

Scope reach: new model module and consumers in renderer/UI; entry HTML/styles; package.json and lockfile/config; earth outline data/assets; node:test tests; README and QA report. No existing callers/config to migrate. New math API is builder-owned; parent will inspect before integrating.
