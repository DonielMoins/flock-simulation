# Temporary globe flock simulation

User request: a temporary project simulating multiple bird flocks with rules affected by seasons, time and conditions around the globe's poles; the globe must be controllable.

Interpretation: 'polls' means geographic poles; control means rotate, zoom and reset view. Proposed minimum behavior: separate flocks with cohesion, alignment and separation; date and UTC time with play/pause and speed; opposing hemisphere seasons, latitude-dependent daylight including polar day/night, and illustrative seasonal migration. Simulation is educational/toy behavior, not validated species forecasting. No live bird observations, weather API, accounts, backend, persistence or deployment requested.

Visual surface: one desktop simulation workspace with dominant globe, side controls, flock legend and month timeline. Responsive implementation and keyboard controls must be verified after approval. Counts and raster UI text are illustrative and not authoritative.

Gate: generate one immutable GPT Image 2 candidate, inspect it, present its exact path and request explicit approval before writing application UI code. Current version: v001, candidate. A mockup is not a functioning simulation.

Implementation scope after approval: app entry/rendering, spherical flock and solar/season calculations, input controls, styling, package scripts/config, focused deterministic tests, README and browser QA evidence. Prefer a static browser app, no backend. Existing temporary directory has no application code to index yet; index when code exists before structural exploration. Do not modify unrelated projects.
